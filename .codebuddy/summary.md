# Project Summary

## Overview of Technologies Used
The project is primarily developed using the **Java** programming language. It employs the **Spring Framework** for building the application, with specific focus on Spring Boot for simplifying the setup and development process. The project also utilizes several key libraries and tools such as:

- **Maven** for dependency management and build automation.
- **Postman** for API testing with multiple collections for different scenarios.
- **PlantUML** for diagramming workflows.

## Purpose of the Project
The project appears to be a workflow management system for bank processes, specifically focusing on the minor account opening process. It includes various features for handling different scenarios (both positive and negative) and integrates state machine logic to manage the workflow effectively.
